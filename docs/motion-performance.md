# 透明背景与交互性能复测

2026-10-20，基准为 Sites 版本 5 / Git 提交 `fb601c5`。本次把点云卡片改为全站透明背景，保留修图对比与作品转场。

## 测量条件

本机 Chromium、Next.js 生产构建、1440×1000 CSS 视口、设备像素比 2、CDP CPU 4 倍降速。两版使用同一脚本：页面加载后等待 1.8 秒，静止 6 秒；发送 36 次 95px 滚轮输入，间隔 100ms；对比滑块拖动 90 步，间隔 16ms。使用 CDP Performance 的累计 TaskDuration 差值；点云绘制时长从 Canvas clearRect 到最后一次 fill 计时。最终复测单独执行，避免并行浏览器任务干扰。

| 场景 | 修改前主线程任务时间 | 修改后主线程任务时间 |
| --- | ---: | ---: |
| 静止 6 秒 | 926ms | 138ms |
| 连续滚动 | 1323ms | 912ms |
| 对比滑块拖动 | 611ms | 353ms |

滚动场景脚本时间从 601ms 降为 126ms，对比拖动从 136ms 降为 38ms。点云绘制平均时间从 4.59ms 降为 0.62ms，p95 从 5.4ms 降为 1.0ms。滚动及对比拖动场景中新背景均为 0 次重绘。该结果是固定本地场景的单次前后复测，包含点云停止空闲动画的收益，不是所有设备的帧率、INP 或线上用户体验保证。

## 改动依据

- 点云几何预计算，每帧两个批量路径，取代逐点改色和独立 fill。
- 全屏透明画布最多 90 万像素；840 点桌面、360 点触屏/窄屏。
- 首次动画短于 5 秒，随后鼠标动作触发短时绘制；滚动、按下指针、后台和减少动态效果时停绘。触屏默认静态。
- 演示对比图的滤镜结果保存为 WebP，浏览器仅裁切两张普通图片。
- 原生滑块直接更新局部 CSS 变量和可访问值，不逐步重渲染 React 图片树。
- 移除 Lenis 运行时滚轮接管，保留浏览器原生滚动。复现条件为滚轮 700px、等待 100ms 后瞬间回顶：旧版本 500ms 后自行漂移 607px，新版本保持 0px。GSAP 入场和封面转场继续保留。

## 验证与回退

生产构建、TypeScript、ESLint、Impeccable 检测通过。浏览器验证透明覆盖、无额外文字/控件、不拦截点击、空闲/滚动/拖动停绘、指针响应、比较拖动/键盘/重置、分类和详情导航、深色主题、减少动态效果、360/390/768px 布局、触屏、无 JavaScript 及 Canvas 不可用回退。Safari 和实体手机未实测。

保留原有 `.gitignore` 用户改动。发布后可重新部署 Sites 版本 5；源码按本次提交回退后重建。
